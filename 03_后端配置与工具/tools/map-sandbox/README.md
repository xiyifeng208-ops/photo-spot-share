# 地图渲染沙箱

用来回答一个问题：**地图渲染不出来，是开发者工具的环境问题，还是我业务页面的问题？**

## 怎么用

1. 微信开发者工具 → 导入项目 → 选这个目录（`tools/map-sandbox`），AppID 填你正式项目那个
   （`wx4ac26aa88091983a`），或者点「测试号」。
2. 详情 → 本地设置 → 勾选「不校验合法域名、web-view、TLS 版本以及 HTTPS 证书」。
3. 编译，看两个页面。

## 怎么看结果

首页有四格，每格下面有一行状态文字：

| 现象 | 结论 |
| --- | --- |
| 格子①-③出现「updated 已触发」，能看到底图 | 地图组件在你这台机器上正常 → 问题在正式页面的结构或配置 |
| 格子出现「updated 已触发」但底图还是灰的 | 组件初始化了但瓦片没加载 → 网络/渲染问题 |
| 三格都停在「等待事件…」 | 地图组件根本没初始化 → 开发者工具/环境问题，代码改不动 |

第二页（custom 导航 + 100vh）完全复刻正式项目地图页的写法，用来判断是不是页面结构导致。

再点一下「调用 getRegion」按钮：

- 出现 `✅ getRegion 成功` → 接口正常，业务页面拿不到视野是别的原因
- 出现 `⛔ getRegion 3 秒没有回调` → 这就是正式页面卡在"加载中"的直接原因

## 还可以顺手换一个变量

如果这里也渲染不出来，把「详情 → 本地设置 → 调试基础库」换一个版本（比如换到上一个稳定版）再编译。
基础库版本是导致 map 白屏的常见原因之一，换一次就能排除。
