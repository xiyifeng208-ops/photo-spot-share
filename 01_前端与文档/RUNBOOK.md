## 日常运行

1. 双击 `start-local.cmd`，依次等待数据库启动、增量迁移、API 启动，保持窗口打开。已有 API 时先在它的窗口停止，不重复启动；迁移失败时保留报错，不删除数据库、不重跑种子数据。
2. 浏览器打开 <http://localhost:3000/health>，确认返回 `status: ok`、`database: up`。
3. 微信开发者工具导入项目下的 `miniprogram/`，选择“小程序”“不使用云服务”，使用有开发权限的 AppID 或自己的测试号。
4. 在“详情 → 本地设置”勾选“不校验合法域名、web-view、TLS 版本以及 HTTPS 证书”，然后编译。
5. 停止使用：先在后端窗口按 `Ctrl+C`（若询问终止批处理，输入 `Y`），再双击 `stop-local.cmd` 停止数据库。后者只停止数据库，不停止 API。

修改 `api/.env` 后：停止 API，再双击 `start-local.cmd`；数据库可以保持运行。

本次升级后重新启动一次后端，并在开发工具点击“编译”，手机重新预览扫码。收藏表随数据库一起备份与恢复，无需单独复制；但收藏属于原用户身份，新的开发设备身份不会自动继承旧清单。

1.3 的发布草稿保存在手机或开发工具自己的小程序数据中，不在后端数据库内，不能随项目复制到新电脑。更换设备或清理小程序数据前，先完成需要保留的草稿；本版没有草稿导出或跨设备恢复。

## 手机验证

1. 手机和电脑连接同一个 Wi-Fi，保持后端窗口打开。
2. 手机浏览器访问 <http://10.3.0.103:3000/health>，确认 `status: ok`、`database: up`。手机上不能用 `localhost` 访问电脑。
3. 开发者工具点击“预览”，用有权限的微信号扫码；需要在电脑查看手机日志时，使用“真机调试”。
4. 若提示域名不合法，在手机小程序右上角 `…` 中开启“开发调试／打开调试”，再重新进入。
5. 进入“发布机位”，允许位置权限，点击“用我的位置”或拖动地图，确认地址自动更新；上传照片发布测试机位，再从列表进入详情验证。

若换网络：运行 `ipconfig`，把 `miniprogram/config/index.js` 中 `DEV_API_URLS` 的 Wi-Fi 地址改为电脑当前 IPv4，然后重新编译、预览扫码。备用 `192.168.137.1` 仅在电脑移动热点实际使用该地址、手机连上该热点时有效。

## 高德 Key

进入[高德控制台](https://console.amap.com/dev/key/app) → 应用管理 → 创建应用 → 添加 Key，服务平台选择 **Web服务**。

在 `api/.env` 填写以下配置并重启 API，Key 仅保存在后端，不写入小程序代码或本文档：

```env
AMAP_KEY=你的高德Key
```

在项目根目录打开 PowerShell 验证：

```powershell
.\.local\node\node.exe .\tools\check-amap.mjs
```

出现 `source: amap` 和“高德逆地理已生效”表示接入成功。未配置或调用失败时，发布页仍可手填地址。

## 换电脑后的恢复流程

适用于新的 Windows x64 电脑；以下命令均在新电脑的项目根目录执行。

1. 保留当前最新源码及上述启动脚本。若改动尚未上传 GitHub，直接下载仓库会缺少这些文件；可复制当前项目源码，但不带 `.local/`、`api/node_modules/`、`api/dist/`。需要保留已发布内容时，先按下一节备份。
2. 在项目根目录运行：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup-portable.ps1
   ```

3. 等待脚本完成下载、数据库初始化、依赖安装和测试。
4. 在新生成的 `api/.env` 中重新填写高德 Key，以及需要保留的其他配置。`api/.env` 不会随 GitHub 下载，旧配置应另行妥善保存。
5. 用 `ipconfig` 查看新电脑 IPv4，并更新 `miniprogram/config/index.js` 中的 `DEV_API_URLS`。
6. 如有备份，先恢复数据库与图片；再双击 `start-local.cmd`。安装微信开发者工具、导入 `miniprogram/`，按前文验证电脑、手机及高德。

便携环境约占 1.85 GB。`.local/` 和 `api/.env` 已被 Git 忽略，不会上传到仓库。

## 迁移真实数据（可选）

只有演示数据时无需迁移，初始化会写入 6 个演示机位。保留自己发布的内容需要同时迁移数据库和图片。

旧电脑先停止 API，保持数据库运行，再在项目根目录执行：

```powershell
New-Item -ItemType Directory -Force backup | Out-Null
.\.local\postgres\pgsql\bin\pg_dump.exe -h 127.0.0.1 -p 55432 -U spot -Fc -f .\backup\spot.dump spot
```

同时复制 `api/var/uploads/`（默认图片目录）和单独保存的 `api/.env`。备份文件及密钥仅用于私下迁移，不提交公开仓库。

把 `backup/spot.dump` 带到新电脑；完成便携环境初始化后，保持数据库运行、API 停止，再执行以下恢复命令。此命令会覆盖目标数据库中的同名业务对象，只用于可以被旧数据替换的新环境：

```powershell
.\.local\postgres\pgsql\bin\pg_restore.exe -h 127.0.0.1 -p 55432 -U spot -d spot --clean --if-exists .\backup\spot.dump
```

将旧图片目录放回新项目的 `api/var/uploads/`，再启动 API，验证旧机位和图片能否正常打开。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 看不到后端窗口 | 正常使用时双击 `start-local.cmd` 会打开窗口；此前由工具后台启动的 API 可能没有窗口。 |
| 启动提示 3000 被占用 | 不要反复启动；先停止已确认属于本项目的旧 API，再启动。不要直接结束未知进程。 |
| 健康检查是 `degraded`、数据库是 `down` | 停止 API 后重新运行 `start-local.cmd`，让脚本先启动数据库。 |
| 电脑可用，手机打不开健康检查 | 检查同一 Wi-Fi、电脑 IP、防火墙和 Wi-Fi 设备隔离；必要时改用电脑热点。 |
| 高德检查提示未配置 Key | 检查 `api/.env` 的 `AMAP_KEY`，重启 API 后再验证。 |
| 扫码提示没有权限 | 使用有该 AppID 开发权限的微信号，或换用自己的 AppID／测试号。 |
