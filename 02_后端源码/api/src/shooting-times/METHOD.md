# 拍摄时间计算说明

核验日期：2026-09-18。独立实现 NOAA Solar Calculator 对应的 Meeus 太阳位置方程（儒略世纪、太阳视黄经、赤纬、时间方程），不使用较低精度的 fractional-year 近似。无需网络、Key、天气服务或新增依赖。

来源：

- [NOAA 计算详情与限制](https://gml.noaa.gov/grad/solcalc/calcdetails.html)
- [NOAA 官方计算器源码，方程和回归参考](https://gml.noaa.gov/grad/solcalc/main.js)
- [NOAA 太阳高度和日出日落阈值说明](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)

只参考数学公式与常数，没有打包第三方源码。NOAA 网页目前声明不再主动维护。本项目结果是摄影时间参考，不承诺观测精度。GCJ-02 机位坐标直接近似使用，不虚构 WGS-84 精确转换；未计算海拔、地形、建筑遮挡及实时大气条件。

在北京时间当日 00:00（含）到次日 00:00（不含）按分钟检查交点，再用二分法细化。日出日落取太阳几何中心高度 -0.833°；黄金时段采用 -4° 到 +6°；蓝调采用 -6° 到 -4°。后两者是本产品的摄影参考阈值，不是 NOAA 给出的摄影效果保证。缺少完整两端点的区间返回 null，不拼接相邻日期。高纬极端掠过可能无法形成稳定的完整时段，因此仍应结合现场判断。

日期只接受 2000-01-01 至 2100-12-31 的严格 YYYY-MM-DD；省略时取北京时间当天。所有返回时间均为显式 +08:00 的 ISO 日期时间，不受服务器系统时区影响。
