# 比赛演示手册

适用版本：功能文档 1.5，2026-09-18。重点展示发现机位、收藏准备、精选路线和草稿续写，可补充近期反馈与拍摄时间助手。本地内容审核关闭，精选路线未经实地验证，不介绍尚未启用的能力。

## 演示前检查

1. 双击项目根目录 `start-local.cmd`，保持后端窗口打开；健康检查应为 `status: ok`、`database: up`。
2. 微信开发者工具导入 `miniprogram` 并重新编译；手机与电脑连接同一 Wi-Fi 或热点后预览扫码。网络地址按 `RUNBOOK.md` 检查。
3. 确认“精选摄影路线”中上海示例可打开，三个站点的图片、文字和顺序正确。没有照片时保留占位，勿冒充实景。
4. 提前用自己的账号收藏一个机位，准备一份含照片的本机草稿，并录制备用演示视频。草稿和开发身份不会从电脑自动同步到手机。

## 三分钟展示顺序

| 时间 | 操作 | 说明 |
| --- | --- | --- |
| 0:00 | 发现页选择上海并搜索外滩或上海 | 搜索已有作品，收藏多的在前；同数时较新作品在前 |
| 0:25 | 清空关键词，展示拍摄条件与结果 | 同类可多选，城市和不同条件共同生效；未知信息不冒充匹配 |
| 0:50 | 进入机位详情并收藏，打开想去清单 | 用样张和拍摄说明决定是否前往，清单绑定当前用户 |
| 1:15 | 打开精选摄影路线 | 武康大楼、外滩、陆家嘴按建议时段展示，不承诺交通时间或实时开放 |
| 1:45 | 从路线进入原机位详情 | 继续收藏或使用已有导航，不新增地图联动 |
| 2:05 | 新建机位，确认省市并填写文字、选图 | 拍摄条件可暂不确定，高德失败时可手动确认地区 |
| 2:30 | 等待草稿保存后退出，在我的页面恢复 | 文字、选点、照片可继续填写；提交成功后该草稿清除 |

若时间充足，在机位详情切换拍摄日期，展示日出日落和黄金、蓝调时段；说明它是理论参考，不含天气判断。查看近 30 天反馈，区分用户意见与核实信息。只在自己的演示机位上演示提交及撤回，不给真实作品制造虚假反馈。

收藏后核对详情数量，返回搜索列表展示自动刷新；清空关键词恢复最新发布，想去清单仍按自己的收藏时间排列。若搜索只匹配一个作品或数量相同，排序差异可能不明显，可用“上海”匹配多个作品；不要伪造收藏数来展示热度。

还可展示编辑后清空标签、独立地图浏览和作者管理。不要为了演示自动删除真实作品或批量举报别人的内容。

## 内容维护与故障兜底

- 路线调整按 `docs/ROUTES.md` 修改配置，不重跑种子或照片导入脚本；保留已有作品、状态、图片和收藏。
- 路线少于两个有效公开机位时暂不展示；先检查机位是否下线或迁往其他城市，不把它当成网络故障。
- 高德不可用时手选省市、填写地址；地图组件异常时可继续列表和路线演示。
- 网络不可用时先核对手机健康检查；必要时使用电脑热点或备用录屏。不要宣称整个小程序可离线运行。
- 保存草稿失败时看页面提示，勿声称已保存；清除小程序数据可能丢失本机草稿。

正式上线仍需公网后端、HTTPS、合法域名、真实微信登录和内容审核联调，比赛演示不代表已完成正式发布。
