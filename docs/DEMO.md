# LIVE DEMO 演示手册

比赛现场要跑起来给别人看，按这份清单准备即可。**代码不需要改动**，只有数据准备和环境启动。

## 一、演示前 15 分钟检查清单

| 步骤 | 命令 / 操作 | 通过标准 |
| --- | --- | --- |
| 1 | 启动数据库：`work\pg\pgsql\bin\postgres.exe -D work\pgdata`（保持窗口开着） | 窗口出现 `database system is ready to accept connections` |
| 2 | 启动后端：双击 `outputs\photo-spot-share\api\restart.cmd`（保持窗口开着） | 出现 `API 已启动: http://localhost:3000/api/v1` |
| 3 | 自检后端与高德：双击 `check-amap.cmd` | 出现 `✔ 高德逆地理已生效` |
| 4 | 开发者工具重新编译 | 打开后默认进入「发现」页，能看到 6 个带样张的机位 |
| 5 | （真机演示才需要）电脑打开「移动热点」，手机连上，确认手机浏览器能打开 `http://192.168.137.1:3000/health` | 显示一段 JSON |

## 二、三条演示路径（按优先级）

**路径 A：真机调试 + 电脑热点（推荐）**
自带电脑与手机，电脑开移动热点让手机连上。开发者工具「预览」或「真机调试」时**勾选「不校验合法域名、
web-view、TLS 版本以及 HTTPS 证书」**。优点：不依赖场地 Wi-Fi，评委能上手真机。

**路径 B：开发者工具模拟器投屏**
最省事，无网络依赖。缺点：地图在模拟器里偶发渲染异常（本项目已做降级：渲染不出来会给出面板 + 一键跳列表）。

**路径 C：录屏兜底**
现场网络或设备出问题时直接放录屏。建议提前用路径 A 录一遍 3 分钟完整流程（发现 → 地图 → 详情 → 导航 → 创建 → 举报）。

## 四、演示数据准备

演示机位默认**没有照片**，卡片会显示"暂无照片"。两种准备方式：

```bash
# 方式一：没有真实照片时，生成 6 张风格化"示例样张"（会标注"示例样张"，不冒充真实照片）
python tools/gen_demo_photos.py
node tools/import-demo-photos.mjs

# 方式二：用自己拍的照片 —— 把照片放进 work/demo-photos/ 覆盖同名文件即可
#   （文件名形如 01-外滩.jpg，脚本按关键词匹配机位；也可放 mapping.json 指定对应关系）
node tools/import-demo-photos.mjs
```

导入后卡片封面、详情页样张都会出现。

**清理调试时发布的垃圾机位**（演示前让数据干净）：

```bash
# 只看一眼有哪些
node tools/import-demo-photos.mjs --help 2>nul
# 用数据库管理工具执行；或把下面命令发给 AI 助手代跑
```

## 五、常见翻车与兜底

| 现象 | 原因 | 现场处理 |
| --- | --- | --- |
| 页面显示"网络不可用（目标 …）" | 手机连不到电脑（不同网段 / 公司 Wi-Fi 客户端隔离） | 改连电脑的移动热点；确认真机调试里勾了"不校验合法域名" |
| 地图一片空白 | 开发者工具原生地图偶发不渲染 | 面板上点「去发现页看列表」继续演示；或点「重新进入页面」 |
| 地址不自动出 | 后端没起 / 高德 Key 失效 | 双击 `check-amap.cmd` 看原因；实在不行手填地址（输入框一直可用） |
| 定位失败 | 手机没给权限 / 未申请 `wx.getLocation` | 演示时用拖动地图选点，不依赖自动定位 |
| 后端窗口被关掉 | 误操作 | 双击 `api\restart.cmd` 重新拉起（约 3 秒） |

## 六、演示环境开关

- `miniprogram/config/index.js`：`ENV='dev'`（演示用局域网 IP，不要改成 prod）、`debug: false`（顶栏不显示调试灰字）。
- 真机演示时后端地址候选是 `10.223.96.34`（当前 WLAN IP，会随 DHCP 变）与 `192.168.137.1`（电脑热点，固定）。
  **推荐现场直接用热点**，地址不会变。
- 内容机审在本地默认关闭（`CONTENT_CHECK_ENABLED=false`），演示时发布即公开，不会停在"审核中"。
