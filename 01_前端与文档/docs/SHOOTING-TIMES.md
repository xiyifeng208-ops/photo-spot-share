# 拍摄时间计算说明

更新日期：2026-09-18。适用功能版本 1.4。

## 使用方式

公开机位详情中选择日期，查看日出、日落、早晚黄金时段和蓝调时段。全程按北京时间（UTC+08:00）展示，不采用手机或电脑本地时区；日期范围为 2000 至 2100 年。不是当前用户所在地的时间，而是所浏览机位的时间。

## 方法与阈值

后端使用 NOAA 太阳计算器对应的 Meeus 太阳位置方程，计算儒略世纪、太阳赤纬与时间方程，再在北京时间所选日期内求太阳高度的交点。代码位于 `api/src/shooting-times/`；不在运行时调用 NOAA、天气、高德或其他第三方接口，不增加 npm 依赖。

| 事件 | 本工具的太阳中心高度定义 |
| --- | --- |
| 日出与日落 | -0.833°，使用常见的太阳视半径与折射近似 |
| 黄金时段 | -4° 至 +6°，分别给出早晚完整时段 |
| 蓝调时段 | -6° 至 -4°，分别给出早晚完整时段 |

黄金与蓝调是本工具选用的摄影参考区间，不是气象观测或保证。缺少交点、没有完整区间时返回 `null`，不以临近日子的时间填补。接口按北京时间返回完整 ISO 日期时间，页面显示时分。

## 来源与限制

算法参考 [NOAA Solar Calculation Details](https://gml.noaa.gov/grad/solcalc/calcdetails.html) 及其太阳计算器公开资料，查阅于 2026-09-18。NOAA 页面说明计算器已不再积极维护；本项目只使用本地计算方法，不依赖其在线服务，不宣称官方认证或观测精度。

项目现有机位坐标为 GCJ-02，本版直接近似用于太阳计算，没有测绘级坐标校正。模型不考虑建筑、地形遮挡、观察者海拔、实时云量和特殊大气状况。实际见到太阳或光线变化的时间可能不同；场地是否开放也需要另行核实。

本版不提供天气预报、日落质量评分、日月方位地图、订阅提醒或自动路线安排。

## 验证与维护

回归覆盖日期校验、北京时间边界、闰年、夏冬时段顺序、高纬无交点、公开状态与不增加浏览量。参考时刻与容差在太阳算法测试中记录；接口与页面的错误应分别显示，不把失败当作当日无太阳事件。

如果以后调整算法或阈值，必须同时修改测试、接口 `method`、本说明和功能文档，不只改页面上的时段名称。
